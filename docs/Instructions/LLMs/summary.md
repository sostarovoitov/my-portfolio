#### Назначение

**Саммари** — это структурированное изложение ключевого контекста диалога, используемое для продолжения работы над незавершенной задачей в новом чате. Составлять его вручную трудозатратно, поэтому лучше поручить эту работу модели: она извлечет из диалога ключевые решения, накопленный контекст, открытые вопросы. Нельзя забывать, что при саммаризации неизбежно теряется часть информации. Это фундаментальное ограничение метода, а не проблема конкретного промпта.

Саммари создаются или в текущем чате, или в новых чатах, в соответствии с требованиями [п. 5 методики](LLM-general-instruction.md#5). 

#### Инструкция по созданию саммари

=== "Создание саммари в текущем чате"

    1. Выберите подходящий промпт для создания саммари в текущем чате из списка ниже.

    2. Скопируйте его и вставьте в текущий чат.

    3. Отправьте запрос и дождитесь ответа модели.

    4. Проведите быструю проверку саммари. Если саммари очевидно расходится с реальным контекстом диалога или очень неполно, отредактируйте отправленный запрос, используя для создания саммари другой промпт. Если результат по-прежнему неудовлетворителен, скорректируйте саммари вручную.


=== "Создание саммари в новом чате"

    1. Выберите подходящий промпт для создания саммари в новом чате из списка ниже.

    2. Скопируйте его и вставьте в новый чат. В конце замените плейсхолдер `[ВСТАВЬТЕ СЮДА ТЕКСТ ДИАЛОГА ДЛЯ СОЗДАНИЯ САММАРИ]` на текст чата, саммари для которого вы хотите создать.

    3. Отправьте запрос и дождитесь ответа модели.

    4. Проведите быструю проверку саммари. Если саммари очевидно расходится с реальным контекстом диалога или очень неполно, вернитесь к шагу 1 и создайте саммари заново с использованием другого промпта. Если результат по-прежнему неудовлетворителен, скорректируйте саммари вручную.

    Если на шаге 2 не удалось отправить запрос из-за превышения лимита символов, либо полученное на шаге 3 саммари оборвалось или явно охватывает только часть диалога, необходимо применить методику **чанкирования**: 

    *  Разделите ваш диалог на отдельные логические фрагменты. При разделении оставляйте небольшое перекрытие — включайте несколько последних сообщений предыдущего фрагмента в начало следующего;

    *  Для каждого фрагмента создайте отдельный новый чат и выполните шаги 2 и 3;

    *  Объедините полученные результаты вручную, устранив дублирование и проверив связность итогового текста, и перейдите к шагу 4 для проведения быстрой проверки.

#### Перечень промптов для саммари

##### Промпт № 1 (Базовый)

!!! info "Когда использовать"
    Подходит для широкого круга задач.

??? note "Для текущего чата"
    
    ```
    Проанализируй историю нашего текущего диалога и создай структурированное саммари по следующим правилам:

    КРИТИЧЕСКОЕ ОГРАНИЧЕНИЕ: Не добавляй информацию, отсутствующую в диалоге. Допускается обобщение и структурирование существующих данных без искажения смысла. Если данных для какого-либо раздела нет — пропусти его. Если в диалоге есть противоречия — отметь их отдельным пунктом в конце саммари.

    Пиши лаконично, в структурированном виде.

    Структура саммари:
    1. Контекст задачи
    Какова была исходная задача.
    2. Ключевые решения и выводы
    Список всех принятых решений и важных выводов. Объединяй только явно дублирующиеся или полностью совпадающие по смыслу пункты.
    3. Установленные ограничения и требования
    Все что было явно запрещено, ограничено или задано как обязательное условие.
    4. Текущий статус и открытые вопросы
    На каком этапе остановился диалог и что осталось нерешенным.
    5. Противоречия (если есть)
    Явные несогласованности в утверждениях или решениях внутри диалога.


    ```

    Какова была исходная задача.
