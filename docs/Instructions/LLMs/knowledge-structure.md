##### Зачем вести базу диалогов

Каждый LLM-сервис хранит историю чатов в собственной экосистеме. Возможности присваивать теги чатам нет: ориентироваться в диалогах приходится только по названиям. При работе с несколькими сервисами навигация становится еще сложнее. Решение этой проблемы — создание единой базы для чатов с LLM. Ниже приведен один из вариантов ее структуры.


##### Структура базы диалогов

База состоит из двух сущностей — **Тема** и **Чат**. 

Тема — направление работы с LLM. С одной темой может быть связано несколько чатов. 

Чат — отдельный диалог с конкретной LLM. Любой чат связан только с одной темой.

##### Таблица «Темы»

| Поле | Тип | Назначение | Комментарий |
|---|---|---|---|
| Название | Title | Краткое название темы | |
| Категория | Select | Основная группировка темы | |
| Теги | Multi-select | Дополнительные метки внутри категории | |
| Описание | Text | Описание темы в свободной форме | |
| Статус темы | Select | Показывает этап жизненного цикла, на котором находится тема | Доступные статусы: «Активна», «На паузе», «Завершена» |
| Чаты | Relation | Связь с таблицей «Чаты» | Содержит перечень всех чатов, связанных с темой |
| Последняя активность | Rollup → из таблицы «Чаты» → Дата | Дата создания последнего чата, связанного с темой | Рассчитывается автоматически при привязке нового чата к теме |

##### Таблица «Чаты»


| Поле | Тип | Назначение | Комментарий |
|---|---|---|---|
| Название | Title | Краткое название чата | |
| Тема | Relation | Связь с таблицей «Темы» | |
| Описание | Text | Описание чата в свободной форме | |
| LLM | Select | LLM, с которой ведется чат | |
| Ссылка | URL | Прямая ссылка на чат | |
| Дата | Date | Дата создания чата | Вводится вручную |
| Статус чата | Select | Показывает этап жизненного цикла, на котором находится чат | Доступные статусы: «Активен», «На паузе», «Завершен» |
| Условия продолжения | Text | Описание событий или изменений, при наступлении которых стоит вернуться к чату | |
| Инсайты | Text | Краткий перечень инсайтов | Выводы и полезные наблюдения, полученные в ходе чата |
| Содержание | Text / Page body | Полный текст чата | |
